My Work

iOS App - Uniway

UniWay is a native iOS solution designed to bridge the mobile accessibility gap. Developed using a scalable SwiftUI architecture, it integrates Total Native Accessibility as its key differentiator. Through the use of CoreImage, I implemented a real-time processing engine that applies color filters (Deuteranopia, Protanopia, and Tritanopia) directly to the interface, allowing users with color blindness to interact with critical elements without loss of information. The experience is further enhanced by AVFoundation for dynamic auditory feedback, along with a comprehensive implementation of VoiceOver and Dynamic Type to ensure universal navigation. Following an 'Inclusive Security' philosophy, the app mitigates vulnerabilities through strict data validation and rigorous management of Privacy Permissions in the Info.plist file, demonstrating that it is possible to create high-impact social solutions that meet the most demanding security standards in real-world environments.

Swift, SwiftUI, iOS Development, Accessibility, CoreImage, AVFoundation

Z80 Processor Simulator

I developed a functional simulator of the Z80 microprocessor using Java, designed as an educational tool to help students understand low-level computer architecture and instruction execution. The project replicates key components of the processor, including the Arithmetic Logic Unit (ALU), control unit, registers, instruction set, and memory management. The simulator was implemented using object-oriented programming principles and data structures to efficiently represent memory, registers, and instruction handling. I designed the architecture to emulate the fetch–decode–execute cycle, allowing instructions to be interpreted and executed similarly to how the real Z80 processor operates. To enhance usability and debugging capabilities, I built a graphical interface using Java Swing that displays processor registers, memory states, and instruction flow in real time. The system also includes step-by-step execution and debugging features, enabling users to analyze how each instruction affects memory and register values. Concurrency was implemented through multithreading to manage execution flow and interface updates simultaneously, improving performance and responsiveness of the simulator. The simulator is currently used by students in the Computer Structure and Programming course as a learning tool to better understand processor behavior, assembly instructions, and low-level system operation

Java, Computer Architecture, CPU Simulation, Data Structures, OOP, Java Swing

Dynamic Concurrency and Process Synchronization Simulator in Java: My Feelings

In this Operating Systems project, I developed a Java application that uses advanced concepts to model the dynamics of human emotions as a concurrent system. My goal was to abstract an everyday problem—the coexistence of feelings—and translate it into a computational model where multiple emotional "entities" are active, influencing each other and changing their intensity non-sequentially. Synchronization Mechanisms and Technical Components: To ensure this system functioned robustly, I implemented the following mechanisms: Thread Management: I used an ExecutorService with a fixed thread pool (newFixedThreadPool) to manage the independent execution of each emotion, which I designed by implementing the Runnable interface. Semaphore Control: I implemented a Global Semaphore limited to 3 permissions. This allowed me to control the number of intense emotions active simultaneously, preventing resource saturation in both the emotional model and the system. Mutual Exclusion: I used Lock objects (ReentrantLock) and Condition Variables to protect access to critical sections, such as the graphical interface update and compatibility checks, preventing race conditions. Compatibility Logic: I defined mutually exclusive emotion groups (such as Joy/Anxiety). I used threads that wait or automatically deactivate depending on the overall system state. Graphical Interface (GUI): I developed the interface in Swing, ensuring smooth and safe progress bar updates using SwingUtilities.invokeLater. What did I learn from this project? This development significantly strengthened my software engineering skills. I learned to abstract real-world problems into structured logical models and to master critical concurrency management, understanding how to avoid deadlocks through the strategic use of semaphores and locks. Furthermore, I refined the synchronization of incompatible processes, where the execution of one thread depends on the state of others, and explored event-driven development to trigger asynchronous background processes. Finally, this project taught me how to optimize the user experience, enabling a technical visualization to reflect realistic behaviors through precise thread control.

Java, Multithreading, Concurrency, Semaphores & Locks, Swing (GUI),Operating Systems

Relational Database Design and Implementation

I designedI designed and implemented a relational database system using Microsoft SQL Server, covering the main stages of database development from conceptual design to implementation. The project started with the creation of an Entity–Relationship (ER) model to identify entities, attributes, and relationships within the system. After defining the conceptual model, I translated it into a logical relational schema, applying normalization up to Third Normal Form (3NF) to eliminate redundancy and maintain data integrity. I then implemented the database using Transact-SQL (T-SQL), creating tables, constraints, and relationships using primary and foreign keys. To support data operations and improve maintainability, I developed stored procedures, triggers, views, and functions that automate processes and enforce business rules directly at the database level. I also optimized query performance by implementing indexes and efficient SQL queries, including joins, subqueries, and aggregation functions.

SQL Server, T-SQL, Database Security, Data Integrity, Stored Procedures, Indexing
